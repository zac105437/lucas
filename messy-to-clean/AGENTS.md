# Project Instructions

## Project

Name: messy-to-clean

This file explains how to work on this project.

## Folder Map

| Path | Purpose |
|---|---|
| `README.md` | Project home page and progress log |
| `AGENTS.md` | Project instructions and rules |
| `.gitignore` | Prevents private data files from being uploaded |
| `data/raw/` | Original datasets |
| `data/interim/` | Intermediate datasets |
| `data/processed/` | Cleaned datasets |
| `notebooks/` | Exploration and experiments |
| `src/` | Reusable code |
| `reports/` | Reports, final PDF and slides |
| `reports/figures/` | PNG charts and figures |
| `references/` | Assignment materials and feedback |

## Rules

1. Never change files in `data/raw/`.
2. Save cleaned data in `data/processed/`.
3. Put reusable code in `src/`.
4. Save charts in `reports/figures/` as PNG files.
5. Never put data files on GitHub.
6. After every work session, add a row to the Progress Log in `README.md`.
7. Always give the exact file path and a code block for every file.
8. Explain everything in simple English.
9. Ask before deleting anything.

## Working Process

1. Read the project README.
2. Check the original data without changing it.
3. Explore the data in notebooks.
4. Clean and process the data.
5. Save cleaned results in data/processed/.
6. Save reusable code in src/.
7. Create PNG charts in reports/figures/.
8. Write the report in reports/.
9. Update the Progress Log in README.md.

## Important

Keep all assignment work inside this project.

Follow these instructions whenever working on messy-to-clean.
